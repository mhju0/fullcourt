Limits and release acceptance

This audit inspected changed source and relevant existing controls, ran dependency and API contract checks, and read the live edge configuration. It did not perform destructive testing, database access-policy changes, a full infrastructure penetration test, or physical-device/VoiceOver testing. Exact-commit independent review, preview verification and production readback are recorded in the release receipt after completion.

Reproduction evidence is retained locally under docs/audit/mobile-2026-10-21/. Project release notes and Git history identify the final candidate.
