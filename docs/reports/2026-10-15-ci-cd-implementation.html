Before: Escape lost focus after opening the command palette from its footer button or keyboard shortcut. A stronger synchronous close/reopen test also lost the original opener. After: focus returns to the connected original control; reopening retains input focus; choosing a route suppresses restoration. This narrow correction was reported before implementation and is included in F2. Broader UI suggestions from the earlier audit remain separate.
