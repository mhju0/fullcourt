## Coverage and interpretation

The NBA [announced public reports on March 2, 2015](https://pr.nba.com/last-two-minutes-reports-officiating/),
starting with March 1 games. Thus 2014–15 is a partial season. These counts cover every regular-season
report linked in the captured [archive index](https://official.nba.com/nba-officiating-last-two-minute-reports-archive/)
for the nine added seasons. Index completeness does not prove that every eligible game was reported.
Playoffs remain outside the published section.

The NBA [changed eligibility and review rules in 2017–18](https://official.nba.com/nba-announces-changes-to-last-two-minute-reports/).
The earlier five-point rule at the two-minute mark and the subsequent three-point-at-any-time rule select
different games. A long season strip is descriptive; it does not measure changing whole-game accuracy.
Shooting fouls lead the recent three-season study, but not every historical season: personal fouls have
37 identified errors versus 35 shooting fouls in the partial 2014–15 sample.

Historical source grades `Undetectable`, `NCI`, and `NCC` are retained and excluded from IC/INC error totals.
The latter two source codes are not silently corrected to a guessed meaning. Missing category or verdict
text stays missing. Older PDF video links have not been independently resolved; the original PDF is linked,
and the interface says Video unavailable. Crew assignments are shown only when previously verified.

## Evidence and validation

- [Source manifest](2026-09-09-l2m-archive-manifest.json) retains each original URL and source hash, plus the index hash.
- Source PDFs are kept in the ignored local snapshot. Each normalized report retains its original PDF URL,
  hash and parser version. The publisher verifies both source and normalized hashes before publication.
- PDF header date and teams resolve against read-only database game identities; no database writes were made.
- Extraction checks match assessment rows to comment blocks. An independent coordinate-based census of the
  PDF Review Decision column agrees on IC/INC counts in all 1,665 PDFs: [audit result](2026-09-09-l2m-pdf-grade-audit.json).
  This second check caught two detached grade labels before publication; regression tests now cover both layouts.
- [Reviewed duplicate rows](2026-09-09-l2m-archive-reviewed-duplicates.json) are pinned to source hashes.
  Printed assessments are retained, including two same-clock ten-second free-throw violations in one report.
  Counts are NBA assessment rows, not a deduplicated count of physical incidents. Unknown duplicate patterns fail publication.
- All 4,546 published game counts are checked against their detail events. All 12 season totals are pinned.

## Reproduction

Requires `curl`, Poppler's `pdftotext`, Python, and the existing read-only database environment for identity export.
Install the project's Python requirements for the export command. Raw snapshots remain ignored; do not edit published figures.

```sh
python3 ml/collect_l2m_archive.py --out ml/data/l2m-research/archive-20260909
ml/.venv/bin/python ml/export_l2m_game_identities.py --out ml/data/l2m-research/archive-games.json
python3 ml/normalize_l2m_archive.py ml/data/l2m-research/archive-20260909 --games ml/data/l2m-research/archive-games.json
python3 ml/audit_l2m_pdf_grades.py ml/data/l2m-research/archive-20260909/normalized --out ml/data/l2m-research/pdf-grade-audit.json
python3 ml/publish_officiating.py ml/data/l2m-research/archive-20260909/normalized/20* --duplicate-review docs/research/2026-09-09-l2m-archive-reviewed-duplicates.json
```

Source revisions can change hashes or duplicate pairs. Review the new evidence instead of automatically accepting
old exceptions. The publication command preserves other published seasons; initial modern-season snapshots are
listed in [Officiating operations](../OFFICIATING.md).
